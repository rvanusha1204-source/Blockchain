## Overview

**DAANSETU** is a smart donation platform designed to bring greater transparency, accessibility and trust to the donation process.

The project combines **Blockchain technology and Artificial Intelligence** to create a more transparent donation ecosystem while exploring intelligent features such as fraud detection, multilingual assistance and donation tracking.

The name **DAANSETU** represents a bridge between **people who want to contribute and causes that need support**.

---

## The Problem

Traditional donation systems can face challenges such as:

- Limited transparency in donation transactions
- Difficulty tracking where donations go
- Lack of intelligent fraud monitoring
- Accessibility barriers for users who prefer regional languages
- Limited visibility into donation activity

DAANSETU approaches these challenges through a combination of **blockchain transparency and AI-powered functionality**.

---

## The Solution

DAANSETU brings multiple technologies together into one platform.

**Blockchain**  
Provides a foundation for transparent and immutable transaction records.

**Artificial Intelligence**  
Used for intelligent analysis and fraud detection.

**Multilingual AI**  
Provides chatbot-based assistance with support for Indian languages.

**Donation Tracking**  
Improves visibility into donation activity.

---

## Key Features

### Blockchain-Powered Transactions

Blockchain technology is used to support transparent and immutable donation records.

### AI-Based Fraud Detection

An AI-based approach is incorporated to identify potentially suspicious donation activity.

### AI Chatbot

An intelligent chatbot assists users and answers donation-related questions.

### Multilingual Accessibility

The chatbot supports responses across **10 Indian languages**, helping make the platform more accessible.

### Donation Tracking

The platform focuses on improving visibility into donation activity through tracking.
